Arco JSON Inspector

Ferramenta interna de QA para sanitizar e comparar arquivos JSON brutos do Arco Motion sem abrir o projeto no app.

Uso correto

Esta ferramenta lê o arquivo como texto local pelo navegador. Ela não chama funções do app, não executa migração, não normaliza frames, não recalcula ProjectWorld e não altera o arquivo original.

  1. Escolha o JSON original em Arquivo A.
  2. Escolha o JSON salvo novamente sem alteração em Arquivo B.
  3. Clique em Sanitizar e comparar.
  4. Baixe os snapshots leves e/ou o relatório de diferenças.

Objetivo: separar se o bug antigo de round-trip está em viewport/editor state, ProjectWorld, assets, frames, curvas ou campos temporários que entraram no save.
